# Все промокоды

Лабораторная работа №1. Каталог демонстрационных скидок на доставку еды и продуктов.

## Запуск

В корне проекта выполните команды в терминале с Node.js и npm:

```sh
npm ci
npm run build
npx --yes http-server@14.1.1 . -a 127.0.0.1 -c-1
```

Откройте [http://127.0.0.1:8080](http://127.0.0.1:8080). Для пересборки CSS при изменении SCSS можно запустить `npm run dev` в другом терминале.

## Структура

- `index.html`, `catalog.html`, `register.html`, `login.html` — главная, каталог и формы. Страница `store.html?store=...` показывает предложения выбранного магазина.
- `styles/` — общие стили и переменные. Кнопки, карточки, формы и окно промокода находятся в `styles/components/`.
- `scripts/offers.js` — магазины и восемь предложений. У предложения типа `code` есть код и условия. Предложение типа `link` открывает адрес из поля `url`. В это поле можно записать реферальную ссылку.
- `scripts/catalog.js`, `scripts/offer-dialog.js`, `scripts/forms.js` — вывод карточек, фильтры, окно промокода и проверка форм.

Данные и условия учебные. Ссылки акций ведут на сайты сервисов. Формы работают в браузере и не сохраняют введённые значения.

## Что показать на защите

1. Перейти с главной в каталог. Показать четыре колонки карточек на главной при 1440 px и две при 360 px. В каталоге выбрать магазин через боковое меню или список на телефоне.
2. Включить фильтр «Промокоды». Открыть карточку, раскрыть условия и скопировать код. На 360 px окно открывается снизу, на 1440 px — по центру.
3. Включить фильтр «Акции» и открыть сайт магазина нажатием на карточку. Открыть страницу магазина из меню «Магазины», переключить категорию и раскрыть условия. Открыть каталог через меню «Предложения». Ввести название магазина, скидку или код в поиск.
4. Отправить пустую форму регистрации. Затем проверить неверный email, пароль из 7 символов и несовпадающие пароли. Исправить поля и показать сообщение об успешной проверке.
5. Открыть страницу входа и показать историю Git. Объяснить, как обработчик `submit` отменяет отправку и выводит ошибки рядом с полями.
